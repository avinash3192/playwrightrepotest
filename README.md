# playwright-automation

JavaScript Playwright Test project with page objects, fixtures, and test data.

## Layout

- `tests/e2e` — browser specs
- `tests/api` — API specs
- `pages` — page objects
- `fixtures` — shared Playwright fixtures
- `testdata` — static test data
- `utils` — helpers

## Commands

```bash
npm test
npm run test:ui
npm run report
```

Copy `.env.example` to `.env` and set `BASE_URL` when you point tests at another app.
